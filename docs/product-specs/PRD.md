# HAJA — 제품 요구사항

## 목적

HAJA는 이벤트 히스토리 모델과 불렛저널 시스템을 결합한 하루 단위 태스크 관리 도구이다.
핵심은 날짜별 기록, 상태 변화 추적, 미완료 태스크의 자동 이관이다.

## 핵심 동작

- 접속 시 해당 날짜의 태스크 화면 표시
- FAB 버튼으로 즉시 태스크 추가
- 새 태스크의 초기 상태는 todo
- 상태 아이콘 클릭/롱프레스로 상태 변경
- 더블클릭으로 수정
- 드래그로 순서 변경 가능
- 완료/취소되지 않은 태스크는 다음날로 자동 이관
- 과거 날짜에는 완료/취소된 태스크만 남음

## 핵심 도메인

태스크(Task)는 클래스 기반 객체로 관리한다.

### Task 속성

| 속성 | 설명 |
|------|------|
| id | 고유 식별자 |
| state | todo / 진행중 / 연기 / 취소 / 완료 |
| creationDate | 생성일 |
| doneDate | 완료일 |
| task(name) | 태스크 이름 |
| description | 상세 설명 |
